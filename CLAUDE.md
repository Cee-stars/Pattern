# 英語パターンノート

Study app for English sentence patterns. Two ways it runs, from the same `index.html`:

- **claude.ai artifact** (https://claude.ai/artifact/9pc3ToG2h8DAfmKgW6GkCK): patterns live in the
  artifact's `db` collection `patterns`; memo autofill uses the `sample` capability.
- **Standalone app** (GitHub Pages from `docs/`): shared patterns come from `patterns.json`;
  the user's own additions/edits and progress live in the browser (localStorage), with backup/restore.

## Adding a pattern the user sends in chat

Do all of these so every device gets it:
1. Write the doc to the artifact db (`ArtifactData` set, collection `patterns`, a readable kebab-case id).
2. Add the same object (with `"id"`) to `patterns.json`.
3. `python3 build_pages.py`, then commit and push.

Pattern shape: `title, formula, meaning, parts[], steps[{h,b}], tips[], examples[{jp, en, hint}], decoys[], createdAt, updatedAt`.
In `examples[].en`, parts are separated by ` / ` and line up with `parts[]` (they get one colour each).

## After changing index.html or icons

Republish the artifact from `index.html`, run `python3 build_pages.py`, commit and push.
Icons are generated by `icons/make_icon.py` then `node icons/render.js`.
